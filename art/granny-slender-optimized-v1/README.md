# Granny, Дед и семья Слендерины — оптимизированные копии V1

Обработаны **35 анимированных GLB и 12 иконок** текущих версий:
Granny V4, Дед, Слендермен, Слендерина и мама-паук, включая по шесть
костюмов каждого персонажа. У мужчин королевский образ — Король.
Исходники и их статусы согласования сохранены. Это отдельный пакет для
просмотра и будущего импорта. **В игру, Studio, `src`, `art/ui` и плейс
ничего не добавлено.**

## Измеренный результат

МБ ниже — 1 000 000 байт. Сравниваются альтернативные наборы основных
анимированных GLB и одного размера PNG. Blender, FBX, история версий,
дублирующие статические позы и обзорные рендеры не входят в эти суммы.

| Набор | Исходники | Компактные копии | Уменьшение |
| --- | ---: | ---: | ---: |
| 35 GLB, в каждом Idle + Aggressive | 30,96 МБ | 24,16 МБ | 21,97% |
| 12 иконок, PNG 512×512 | 9,84 МБ | 2,05 МБ | 79,14% |
| GLB + иконки 512 | 40,80 МБ | 26,21 МБ | 35,77% |
| 12 иконок, PNG 256×256 | 9,84 МБ | 0,64 МБ | 93,53% |
| 12 иконок, PNG 1024×1024 | 9,84 МБ | 6,84 МБ | 30,50% |

Готовый ZIP `GrannySlender_Models_Icons512.zip` — **7,43 МБ**. Он содержит
только 35 GLB, 12 PNG 512, локальный манифест и краткую инструкцию.
CRC архива и совпадение распакованных байтов проверены. Это архив для
передачи/хранения набора; игра не загружает этот ZIP автоматически.

Количество мешей в сумме: **843 → 49**. У Granny и Деда по два меша:
тело и оружие; у трёх остальных персонажей по одному. Сохранены все
**219 168 треугольников**, 488 111 вершин и **623 кости** в 35 моделях.
Количество ключей: **39 382 → 35 434** за счёт константных каналов;
все движущиеся ключи, их значения и исходная интерполяция сохранены.

Наличие исходников, разных размеров PNG и сравнений увеличивает общую
рабочую папку. Выигрыш выше относится к выбранному набору для будущей
загрузки, а не к сокращению всего репозитория. Старые версии не удалялись.

## Какой набор использовать

| Путь | Назначение |
| --- | --- |
| `models/` | 35 компактных GLB со скелетами и обоими клипами |
| `icons/ui512/` | Предлагаемый размер PNG для обычных карточек |
| `icons/small256/` | Дополнительный размер для маленьких элементов |
| `icons/large1024/` | Дополнительный размер для крупных портретов |
| `runtime_manifest.json` | Локальные пути, имена, роли, клипы и SHA-256 |
| `GrannySlender_Models_Icons512.zip` | Отдельный набор GLB + PNG 512 |

Каждый основной GLB уже включает `Idle` (2,4 с) и `Aggressive` (1,2 с).
Отдельные GLB-снимки этих же состояний не нужны в этом наборе для импорта.
Редактируемые Blender и FBX остаются в исходных художественных пакетах.

## Изменения моделей

Все части с одним материалом объединены в skinned mesh. Имя объекта теперь
`<Character>Body`, у Granny/Деда также `<Character>Weapon`. Лицо, пальцы,
волосы и костюм продолжают двигаться своими костями внутри объединённого
меша. Исходные детали и диапазоны их треугольников перечислены в
`models_report.json`. Такой набор предназначен для скелетного импорта;
контроллер, который обращается к старым отдельным Parts/мешам, потребует
адаптации. В игровой код эти изменения не вносились.

Позиции и нормали треугольников остаются float32 без округления. Имена,
порядок и иерархия костей, bind-матрицы и исходные движущиеся ключи
сохранены. Цвета и веса записаны нормализованными uint16 по основному
[стандарту glTF 2.0](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html).
Сумма целочисленных весов каждой вершины равна 65535. RGB дополнен
непрозрачным альфа-каналом для корректного выравнивания данных.
Draco, meshopt, KHR_mesh_quantization, новые текстуры и внешние декодеры
не используются.

Постоянный канал удаляется только при точном совпадении со статическим
значением узла. Остальные константные каналы оставлены с одним ключом.
LINEAR и STEP сохраняются. Времена, значения и число движущихся ключей
не изменены; длительности обоих клипов сохранены.

Объединение мешей уменьшает количество отдельных объектов, но это не
измерение draw calls в Roblox. После разрешённой интеграции понадобятся
замеры на целевых устройствах: [документация Roblox по производительности](https://create.roblox.com/docs/performance-optimization/improve).

## Изменения иконок

Исходный рисунок не перегенерировался. Из PNG RGBA 1254×1254 получены
1024, 512 и 256 с LANCZOS, затем сохранены PNG со сжатием без изменения
полученных пикселей и без необязательных метаданных. Композиция, поля и
прозрачность сохранены. На тёмном и светлом фоне проверены варианты при
показе в 64, 96 и 128 px. Максимальная средняя разница для PNG 512 —
0,6003 уровня из 255 на цветовой канал среди этих сравнений.

Число пикселей набора PNG 512 меньше исходного на 83,33%. Его сырые RGBA8
данные занимают 12,58 МБ вместо 75,48 МБ; это расчёт для RGBA8, а не замер
памяти игры. Roblox подбирает качество текстур по ресурсам устройства,
поэтому вес PNG на диске и память/время загрузки в движке различаются:
[спецификация текстур Roblox](https://create.roblox.com/docs/art/modeling/texture-specifications).

## Проверка и просмотр

- `previews/Model_Comparison.png` — исходные и компактные модели рядом.
- `previews/Grip_Comparison.png` — кисть Granny в обоих состояниях и ружьё Деда.
- `previews/Icon_Comparison.png` — один рисунок при разных разрешениях.
- `previews/All_Icons_512.png` — все 12 иконок 512.
- `previews/comparisons/` — отдельные сравнения 11 ракурсов/состояний.
- `source_inventory.json` — хеши 531 исходного файла, ни один не изменён.
- `packing_validation.json` — точное сравнение углов треугольников, нормалей,
  скелетов и ключей, независимый расчёт скиннинга на 14 временах на модель,
  включая промежуточные кадры: всего 490 проверенных поз.
- `blender_validation.json` — повторный импорт всех 35 GLB, оба клипа,
  веса, геометрия, движение головы, оружия и отдельных паучьих лап.
- `visual_validation.json` — сравнение 11 пар рендеров, снятых из GLB с
  одинаковыми камерами, освещением и seed.
- `models_report.json`, `icons_report.json`, `summary.json` — подробности и размеры.

Максимальное отклонение деформированной вершины после упаковки —
0,000001092 единицы исходной сцены. Матрицы костей при воспроизведении
совпадают; максимальная ошибка цвета/веса — около 0,00000763.
У сравнительных рендеров максимальная средняя разница — 0,000186 уровня
из 255, максимальная разница отдельного канала — 3 уровня.
Проверки хватов и внешнего вида относятся к сохранению текущего исходника,
а не меняют статус художественного согласования исходного дизайна.

**Импорт, фактическое время загрузки, FPS и память в Roblox не измерялись.**
Весь результат остаётся локальным набором для просмотра.

## Воспроизведение

Скрипты пишут только в эту папку. Для моделей используется NumPy, уже
входящий в Blender 5.2.3, для иконок/листов — Python с Pillow.

```sh
blender -b --factory-startup --python-exit-code 1 --python art/granny-slender-optimized-v1/build_models.py
python3 art/granny-slender-optimized-v1/build_icons.py
blender -b --factory-startup --python-exit-code 1 --python art/granny-slender-optimized-v1/validate_packing.py
blender -b --factory-startup --python-exit-code 1 --python art/granny-slender-optimized-v1/validate_blender.py
blender -b --factory-startup --python-exit-code 1 --python art/granny-slender-optimized-v1/render_comparison.py
python3 art/granny-slender-optimized-v1/compose_review.py
python3 art/granny-slender-optimized-v1/finalize.py
```
