Granny / Grandfather / Slender family: offline compact asset set.
35 rigged GLB models, each with Idle and Aggressive, and 12 transparent PNG icons at 512x512.
Original artwork and authoring scenes are preserved outside this archive.
Models retain all triangle geometry and bones; mesh objects are merged, colors/weights packed to normalized uint16.
These are assets for review and future skeletal import, not an automatic replacement of procedural game rigs.
No Studio import, upload, game registration or runtime performance measurement has been performed.
See runtime_manifest.json for file paths and SHA-256.
