# SRP — 24 иконки на согласование

Статус: ожидают визуального согласования пользователя. В игру и Roblox Studio не добавлены, не загружены. Паразит и базовые формы исключены по запросу пользователя.

Четыре персонажа: Dredge, Assimilated Adventurer, Primitive Summoner, Adapted Viscera.
Для каждого: Фермер, Шахтёр, Король, Рыцарь, Нефор, Убийца. Все руки и отростки без переносимых предметов. Все королевские образы — Короли.

## Файлы

- `icons/`: 24 оригинальных PNG 1254 × 1254, RGBA, прозрачный фон. Исходные пиксели и альфа генерации сохранены без обработки.
- `previews/All_24_Icons.png`: общий лист на согласование.
- `previews/*_Six_Icons.png`: четыре отдельных листа персонажей.
- `previews/Small_Size_Check.png`: просмотр при 96 и 64 px на светлом и тёмном фоне.
- `previews/Style_Comparison.png`: сравнение с существующей игровой иконкой.
- `prompts.json`, `corrections.json`: точные промпты и пути референсов.
- `assets.json`: происхождение файлов; `validation.json`: проверки формата, альфа-канала, границ и неизменности существующих файлов.

Создано встроенным инструментом `image_gen`, по одной генерации на иконку. Две точечные правки также выполнены `image_gen`: отступы PrimitiveSummonerKing и восстановление восьмого отростка AdaptedVisceraKing. CLI и API-ключ не использовались.

Стилевой референс: `art/ui/modal-refresh/DeerFarmer.png` из текущего проекта. Дизайн персонажей и костюмов: индивидуальные 3D-превью из `art/srp-character-variants-v1/previews/`. Иллюстрации интерпретируют геометрию в рисованном стиле; мелкие детали упрощены. На маленьких размерах тонкие зубцы и цепочки сливаются, но основные силуэты и головные уборы различимы.

Скрипт `compose_review.py` только собирает обзорные листы; оригинальные PNG не меняет. Подписи и подложки присутствуют только в превью. Для скриптов необходим Pillow.

Набор предназначен для визуального согласования. Файлы `src`, текущие иконки `art/ui`, исходные 3D-модели и конфигурация игры не изменялись.
