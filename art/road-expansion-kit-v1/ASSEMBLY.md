# Шесть дорог для Roblox Studio

В каталоге `models` лежат 45 отдельных GLB, сгруппированных по биомам. В `samples` — шесть собранных примеров. Каждый пример содержит 512 studs дороги, два ряда фасадов с боковым входом и арену. Откройте `index.html`, чтобы выбрать деталь по названию и посмотреть её в собранном участке.

## Первый импорт

1. Для примерки откройте пустой place. Через **File → Import** выберите файл из `samples`, например `pizza.glb`. Для сборки из деталей выбирайте отдельные файлы из `models/pizza`.
2. В окне импорта задайте **Scale Unit = Studs**, включите **Anchored** и **Set Pivot to Scene Origin**. Для сохранения отдельных деталей отключите **Merge Meshes**. Для локальной примерки отключите **Upload to Roblox**. [Описание настроек Importer](https://create.roblox.com/docs/studio/importer)
3. Проверьте масштаб по плитке `Floor64`. Она занимает 64 studs вдоль дороги и 140 поперёк. Цветовая палитра уже встроена в GLB. Отдельная копия той же текстуры лежит в `textures/RoadPalette.png`.
4. При сборке поверх игровой дороги совместите поверхность пола с существующей игровой плоскостью. Если действующая дорога уже обслуживает столкновения, у декоративного слоя и дорожных предметов можно выключить **CanCollide**. Для сборки в пустом месте физическую поверхность удобно задать обычными закреплёнными деталями.

## Сборка на сетке

Оси указаны для Roblox. X идёт вдоль дороги, Y направлена вверх, Z идёт поперёк дороги. Числа ниже даны относительно середины участка.

| Модуль | Точка привязки и шаг |
| --- | --- |
| Пол `Floor64` | Центр верхней плоскости, Y = 0. Копируйте вдоль X через 64. Для двух секций по сторонам от начала координат используйте X = −32 и +32. |
| Стены `WallA` и `WallB` | Длина 64. Точка привязки внизу, посередине задней плоскости. Ставьте на Z = −70 лицом к +Z. Для противоположной стены используйте Z = +70 и поворот 180° вокруг Y. |
| Арена `Arena` | Точка привязки в центре окружности, радиус 100. Оставьте две соседние позиции стены под вход. При входе между X = −32 и +32 поставьте арену в (0, 0, −150). Для арены справа используйте (0, 0, +150) и поворот 180° вокруг Y. |
| Предметы | Обычный декор ставится на уровне пола. У `SC_Beacon` точка привязки на основании маячка, у `SC_Camera` — внизу настенного кронштейна. У `IR_FloatShards` точка привязки на полу под группой, высота осколков уже заложена в модель. |

Все положения и углы шести примеров записаны в `layouts.json` в этих же осях. В `catalog.json` для каждого модуля указаны файл, русское название, границы геометрии и число треугольников. В образцах фонтан и сцена стоят у дальнего края арены. Центр оставлен под босса.

## Звёздный фон

В `sky` лежат шесть PNG размером 512 × 512. Для космического окружения назначьте их одноимённым свойствам объекта **Sky** в **Lighting**. Например, `SkyboxFt.png` соответствует полю **SkyboxFt**. Для соседства нескольких биомов учитывайте, что объект Sky задаёт небо всей сцены. [Настройка Sky в Roblox](https://create.roblox.com/docs/environment/skybox)

## Исходники

`source/build.py` создаёт модели, примеры, палитру, небо и JSON из исходной геометрии. Для пересборки моделей достаточно Python 3. `source/review.py` запускается в фоновом Blender, импортирует экспортированные файлы, проверяет габариты, число треугольников и координаты сборок, затем рендерит превью. Команда `python3 source/package.py` из папки набора собирает и проверяет итоговый ZIP.
