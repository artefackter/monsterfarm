# Granny и Дед — иконки V3

Полный набор из 12 PNG RGBA с исходной прозрачностью, в прежнем рисованном
стиле интерфейса. В игру, Studio, `art/ui`, runtime и плейс не добавлены.

Изменены семь иконок: шесть Granny с новым разворотом правой кисти и
Дед-Король вместо Деда-Принцессы. Они **ожидают согласования**.
Пять остальных иконок Деда, включая согласованного «Убийцу», скопированы
из V2 без изменения пикселей и альфа-канала. Их согласование сохраняется.

У Granny ладонь направлена к бедру, тыльная сторона кисти наружу;
большой палец проходит по передней стороне рукояти, остальные пальцы
обхватывают её с внутренней стороны. Референс — фактическая новая кисть V4.
У Деда-Короля сохранён согласованный двуручный хват ружья и прежнее лицо;
одежда заменена на синюю королевскую тунику, брюки, меховой воротник,
красную мантию и золотую корону. Предыдущая Princess сохранена в V2 как
история, не входит в текущие шесть образов Деда.

- `icons/` — шесть Granny и шесть Деда; оригинальные сгенерированные PNG.
- `previews/*_Icons_Review.png` — листы шести иконок каждого персонажа.
- `previews/*_Icons_SmallSizes.png` — читаемость в 96 и 64 px.
- `previews/Grip_Fixes_Review.png` — 3D и новые иконки крупным планом.
- `assets.json` — источник и статус каждого PNG.
- `prompts.json` — все семь запросов и референсы.
- `validation.json` — размеры, RGBA, прозрачность, SHA-256 всех 12 PNG.

Использован встроенный `image_gen`, CLI не запускался. Файлы скопированы
из `~/.codex/generated_images` в проект. Пиксели и альфа после генерации
не менялись; ресайз и кадрирование есть только в листах просмотра.
Проверка и сборка листов: `compose_review.py` (Pillow).
