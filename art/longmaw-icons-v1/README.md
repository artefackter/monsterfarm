# Иконки Длиннорота — на согласование

Шесть отдельных рисованных портретов по текущим костюмам Длиннорота:
Фермер, Шахтёр, Принцесса, Рыцарь, Нефор и Убийца.
**Иконки ожидают согласования и в игру не добавлены.**

Использован встроенный `image_gen` по навыку imagegen, без CLI/API fallback.
Референсы — рендер каждого костюма из `art/longmaw-forms-v1` и текущая игровая
иконка `art/ui/modal-refresh/DeerFarmer.png`. Сохранён рисованный стиль:
тёмный сливовый контур, цветная объёмная светотень и яркие блики.

По образцу текущего набора создана одна иконка на костюм, в обычной форме.
Сохраняются четыре длинные лапы, длинное тело, острый горб, вытянутая
сужающаяся пасть, маленькие белые глаза в чёрных глазницах, отсутствие ушей
и хвоста. Инструменты и оружие остаются в креплениях и ножнах.

## Просмотр

- `previews/Longmaw_Icons_Review.png` — все шесть иконок с подписями.
- `previews/Longmaw_Icons_StyleComparison.png` — сравнение с текущими иконками игры.
- `previews/Longmaw_Icons_SmallSizes.png` — читаемость в 96 и 64 px.

Фон и подписи имеются только на обзорных листах. PNG-кандидаты содержат
настоящий прозрачный фон, без рамок, подписей, земли и теней на земле.
Исходные пиксели и альфа-канал генерации не редактировались. Масштабирование
для обзорных листов не изменяет оригиналы.

## PNG

Все шесть файлов — 1254 × 1254 px, RGBA с прозрачным фоном.

| Костюм | Файл |
| --- | --- |
| Фермер | `icons/LongmawFarmer.png` |
| Шахтёр | `icons/LongmawMiner.png` |
| Принцесса | `icons/LongmawPrincess.png` |
| Рыцарь | `icons/LongmawKnight.png` |
| Нефор | `icons/LongmawPunk.png` |
| Убийца | `icons/LongmawAssassin.png` |

- `prompts.json` — полный набор промптов и пути референсов для встроенного image_gen.
- `assets.json` — соответствие ролей, источников генерации и PNG-кандидатов.
- `references.json` — источники дизайна и контрольные суммы референсов.
- `validation.json` — размеры, RGBA, прозрачность, отступы и SHA-256 всех PNG.
- `compose_review.py` — проверка и сборка листов просмотра, Python с Pillow.

Файлы размещены отдельно в `art/longmaw-icons-v1`. `art/ui`, `src`,
`assets/runtime`, плейс и проекты Rojo не менялись. Ссылки в `Icons.lua`
и `MonsterCollection.lua` не редактировались. Загрузки в Roblox и подключения
к игровому интерфейсу не было. Перед добавлением набора требуется его
согласование с владельцем.
