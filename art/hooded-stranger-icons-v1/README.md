# Незнакомец — шесть иконок на согласование

Шесть рисованных иконок по текущим костюмам Незнакомца: Фермер, Шахтёр, Король, Рыцарь, Нефор и Убийца. Созданы встроенным **image_gen** по рендерам из `art/hooded-stranger-forms-v1` и действующей иконке Оленя как образцу стиля.

**Иконки пока не согласованы. В Roblox они не загружались, в игру и интерфейс ничего не добавлено.** Работа выполнена в отдельном пакете; `src`, `art/ui`, `assets/runtime`, манифесты и плейс не менялись.

## Смотреть

- `previews/HoodedStranger_Icons_Review.png` — шесть иконок с подписями.
- `previews/HoodedStranger_Icons_StyleComparison.png` — сравнение с действующими иконками Фермера и Короля.
- `previews/HoodedStranger_Icons_SmallSizes.png` — проверка читаемости при 96 и 64 пикселях.

Светлый фон и подписи есть только на листах согласования. Сами иконки имеют исходную прозрачность генерации; их пиксели и альфа-канал после генерации не изменялись. Незначительные альфа-значения до 3 на границах холста сохранены как часть исходного результата; видимый персонаж не касается краёв.

## Файлы PNG

Каждый файл — **1254 × 1254, RGBA**.

| Форма | Файл |
| --- | --- |
| Фермер | `icons/HoodedStrangerFarmer.png` |
| Шахтёр | `icons/HoodedStrangerMiner.png` |
| Король | `icons/HoodedStrangerKing.png` |
| Рыцарь | `icons/HoodedStrangerKnight.png` |
| Нефор | `icons/HoodedStrangerPunk.png` |
| Убийца | `icons/HoodedStrangerAssassin.png` |

Стиль повторяет текущий набор коллекции: персонаж в полный рост, тёмный сливовый контур, объёмная рисованная светотень, яркие блики и цветовые акценты. Сохранены широкий капюшон, небольшое бледное лицо со скрытыми глазами и узким закрытым ртом, длинные руки и крупные кисти. Изображение лица перерисовано в стиле иконок, а не вставлено как фотографическая текстура. У всех форм обе руки свободны; кирка и оружие остаются в креплениях и ножнах.

Первая иконка Фермера также использована как образец лица, пропорций и отделки для остальных пяти иконок. Одна иконка соответствует одному костюму в нейтральной стойке; дополнительные состояния не создавались.

## Источники и проверки

- `prompts.json` — полные финальные промпты, входные изображения и режим встроенного `image_gen`; CLI не использовался.
- `assets.json` — карта образов, исходных результатов генерации и локальных PNG-кандидатов.
- `references.json` — контрольные суммы исходных рендеров костюмов.
- `validation.json` — размер, формат, прозрачность, видимые границы, SHA-256 и проверка неизменности каждого PNG относительно результата генерации.
- `compose_review.py` — проверка файлов и сборка обзорных листов. Масштабирует изображения только внутри листов, не изменяя PNG-кандидаты.

Для пересборки листов нужен Python с Pillow:

```sh
python3 art/hooded-stranger-icons-v1/compose_review.py
```

Согласование этих кандидатов не означает автоматическую загрузку или подключение к игре. Добавление будет выполнено только по отдельному указанию пользователя после согласования.
