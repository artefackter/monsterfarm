# Верстак — согласованная отдельная модель

Внешний вид одобрен владельцем 13 ноября 2026 года. По его указанию модель
добавлена только как отдельный объект в репозиторий. В Studio не установлена,
игровые исходники, конфигурации сборки и сохранённый плейс не изменены.

`WeaponWorkbench.rbxmx` — готовый объект Roblox Model с 101 закреплённой деталью,
без скриптов и внешних ассетов. Pivot находится в центре основания на уровне
земли. Файл можно вручную вставить в Studio после отдельного разрешения владельца.
Он расположен вне `assets/runtime` и не включён в Rojo-проекты.

`preview.png`, `front.png` — проверенные рендеры модели. Освещение и земля служат
только для превью; это не скриншоты из игры.

`Workbench.glb` — геометрия без сцены превью. `Workbench.blend` — исходная сцена.
`parts.json` и `WorkbenchDraft.lua` описывают ту же модель из 101 стандартной детали
Roblox, без загрузки сторонних ассетов. Модуль ничего не создаёт до вызова Build.
В GLB вертикальная ось преобразована экспортёром; в JSON/Luau используется Roblox Y-up.

Воспроизведение:

```sh
blender -b --python art/workbench-proposal-v1/build.py
python3 art/workbench-proposal-v1/export_roblox.py
```

Только после отдельного разрешения на интеграцию: заменить визуальную часть верстака в PlotService,
сохранить corner, локализованную вывеску и WorkbenchZone (MenuZone, Radius, Owner).
Подключить фонарь и мутаген к существующим NightLight/NightGlow. Проверить
видимость с дорожки, проход у ворот и открытие улучшений в Play. Эти действия
пока не выполнялись.
