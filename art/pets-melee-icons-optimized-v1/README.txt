9 согласованных 2D-иконок — компактные PNG для Roblox

icons/ui512: 512×512, для крупных карточек магазина, как на скриншоте.
icons/small256: 256×256, для небольших элементов интерфейса.
Загружать отдельные PNG нужного размера; ZIP служит только для передачи файлов.
Не требуется загружать обе версии каждой иконки.

Сжатие с минимальными изменениями цвета: RGB округлён до ближайшего значения,
кратного 4; максимальное отклонение видимого канала 2/255. Скрытые RGB при
нулевой прозрачности обнулены. Альфа-канал сохранён побайтно без изменений.
Формат остаётся PNG RGBA8. Цветовая точность слегка уменьшена; это не полностью
без потерь. Геометрия изображения, размеры и контуры альфа-канала не менялись.
Исходники в ../pets-melee-icons-v1 сохранены без изменений.

Все 9 PNG проверены в обоих размерах. previews/Compression_Comparison.png:
слева исходный PNG512, справа сжатый, на светлом и тёмном фоне.
manifest.json: размеры, контрольные суммы, погрешность цвета, ключи иконок.
optimize.py: воспроизводимый скрипт сжатия и проверок.

В Roblox не загружено, код игры не изменён. Roblox может перекодировать
изображения при загрузке. Уменьшение локального PNG не гарантирует такого же
снижения размера доставки или GPU-памяти; фактическая загрузка в игре не измерена.
При одинаковых размерах разрешение и объём несжатых RGBA остаются прежними.
